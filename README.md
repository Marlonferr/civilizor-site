# Civilizor — site base

Arquivos:
- index.html — página inicial
- solucoes.html — página com todas as soluções
- produto.html — página dinâmica de cada produto usando ?id=
- css/style.css — identidade visual e responsividade
- js/products.js — dados/textos dos produtos
- js/script.js — interações

Como testar:
1. Extraia a pasta.
2. Abra `index.html` no navegador.
3. Clique em "Soluções".
4. Clique em qualquer produto.
5. Para alterar os textos dos produtos, edite `js/products.js`.

Exemplos:
- produto.html?id=c-ia
- produto.html?id=c-iot
- produto.html?id=c-data
- produto.html?id=c-cel
- produto.html?id=c-volt
- produto.html?id=c-curity
- produto.html?id=c-sric
- produto.html?id=c-key
- produto.html?id=c-dev

Observação:
O SVG enviado foi usado como referência de composição/estrutura, enquanto o código implementa a interface com HTML/CSS/JS para que você consiga estudar e alterar o projeto.
